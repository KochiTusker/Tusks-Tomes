📚 Documentation

Everything in detail, so the README doesn't have to carry it all. Treat this as the contents page.

If you're starting from scratch, read these three in order and ignore everything else until something goes wrong: Beginner's guide → Workflows → Recommended settings.

If you'd rather know what you're letting onto your machine before installing anything — entirely reasonable — How safe is this? is the honest version, including the parts that could go wrong.
