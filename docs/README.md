# 📚 Documentation

Everything in detail, so the [`README`](../README.md) doesn't have to carry it
all. Treat this as the contents page.

If you're starting from scratch, read these three in order and ignore
everything else until something goes wrong:
[Beginner's guide](beginner-guide.md) → [Workflows](workflows.md) →
[Recommended settings](recommended-settings.md).

If you'd rather know what you're letting onto your machine before installing
anything — entirely reasonable — [How safe is this?](is-this-safe.md) is the
honest version, including the parts that could go wrong.
