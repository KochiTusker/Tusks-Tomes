Self-hosted web fonts — all under the SIL Open Font License 1.1 (OFL-1.1).
Bundled locally so the docs site makes no third-party requests at page load
(consistent with the project's local-first, no-telemetry posture).

Subset: latin. Format: woff2.

The woff2 files carry only standard font name-table metadata (family name,
designer, licence URL) — no personal or build-environment data.
